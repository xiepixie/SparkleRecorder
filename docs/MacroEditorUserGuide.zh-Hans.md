# SparkleRecorder 宏编辑器操作说明

> 文档状态（2026-09-07）：当前宏编辑器与宏库用户说明。它描述单个宏编辑、目标窗口、屏幕动作预览、OCR 选择和动作绑定；Automation / Run Center 的详细流程由对应工作流文档维护。

## 基本心智模型

时间线里的每一行代表一个可理解、可排序、可编辑的动作，而不是底层事件噪音。

底层仍会保留 mouseDown、mouseUp、dragged、keyDown、scrollWheel 等 raw events，用于精确回放和诊断；编辑器默认展示的是语义动作，例如点击、拖拽、等待、点击文字、等待文本、验证文本。

选中动作后，侧栏会在同一个滚动页面中显示动作属性、复制/删除、时间调整和插入入口，不需要在检查器与编排标签之间切换。

复制动作会把副本放在原动作之后，并保留 0.5 秒可见等待，避免两个独立点击被重新识别为双击或连续多点点击。

## 目标窗口

目标窗口不是“此刻位于前台的窗口”。如果直接在 SparkleRecorder 前台读取当前窗口，很容易把 SparkleRecorder 自己错误地绑定成播放目标。

现在应从宏卡片的更多菜单，或菜单栏紧凑行的 `…` 菜单中选择“选择目标窗口…”。SparkleRecorder 会暂时让开自己的窗口并显示选择层；直接点击这个宏之后应该控制的真实应用窗口即可。选择过程不会执行宏，也不会向目标应用发送点击或键盘输入；按 `Esc` 可以取消。

设置成功后，宏卡片会显示目标应用和窗口标题。默认开启“跟随目标窗口位置”：目标窗口移动后，回放坐标会跟随窗口位移，而不是继续使用录制时的绝对屏幕位置。需要固定绝对坐标时可以关闭这一选项。

进入宏编辑器后，Inspector 顶部也会固定显示“目标窗口”这一宏级设置。可以直接查看当前目标、更换或移除目标窗口，并切换“跟随目标窗口位置”，不需要退出编辑器回到宏库。

如果目标窗口已经更换，可使用“更换目标窗口…”重新选择；不再需要窗口约束时使用“移除目标窗口”。播放找不到目标窗口时，也应回到这一入口重新选择，而不是重新录制整个宏。

## 插入位置

右侧插入动作默认插入到当前选中动作之后。

如果选中了多个动作，新动作会插入到选中范围的最后一个动作之后。没有选中任何动作时，新动作会追加到末尾。

## 录完后的检查入口

编辑器侧栏顶部的 Review 区会把录制后的宏整理成几个可处理的状态：

- 缺少文字目标：等待文字、验证文字或点击文字还没有可搜索的目标。
- 固定坐标点击：普通坐标点击可以继续使用；如果目标按钮会移动，可以先绑定为点击文字。
- 长等待：长时间延迟可以保留；如果实际是在等页面出现文字，应改成等待文字。
- 行为块或 Repeat-Until：当选中的动作已经满足条件时，Review 区会给出创建行为块或预览 Repeat-Until 的入口。

顶部工具栏和底部状态栏也会显示当前宏是“缺目标”、“需要可靠性检查”，还是“可以测试”。

## 常用动作

点击：点击固定坐标。适合窗口布局稳定、按钮位置明确的场景。

点击文字：查找目标文字，找到后点击匹配文字框的中心。适合按钮会移动、窗口会缩放、列表内容会变化的场景。

等待：纯等待一段时间，不发送鼠标或键盘输入。

等待文本：等待目标文本出现，然后继续执行后续动作。这个动作本身不会点击。

验证文本：立即检查目标文本是否满足条件。条件不满足时停止播放，并保存失败证据。

拖拽：保留按下、拖动轨迹、松开的完整手势。编辑起点/终点时会尽量保留原始轨迹形状。

按键：编辑一次键盘输入或快捷键。

## 屏幕动作预览

屏幕 Overlay 分成两个彼此独立的层级。`预览`用于查看当前选中动作的详细状态和编辑控件；`轨迹`用于概览整个宏的动作位置与手势路径。两者都关闭时不显示任何编辑器 Overlay；只开`预览`但没有选中动作时也不会凭空创建模拟窗口；只开`轨迹`时显示全局位置关系，但不会开放拖拽编辑；两者同时开启时，全局轨迹作为背景，当前选中动作保持详细、高亮和可编辑状态。

屏幕预览表达的是“如果现在执行，这个动作会以什么方式作用在什么位置”，不是把所有 raw event 都画成鼠标轨迹。动作之间不会用虚线强行连接；只有真正有空间结构的动作才显示路径或区域。

- 普通点击：用精确靶点表示执行坐标，并保留宏时间线中的真实动作序号。双击、连续点击会显示次数；长按会显示持续时间；右键和中键会额外标明按键类型。
- 拖拽：显示真实拖拽轨迹、起点和终点。起点、终点和整条路径都可以直接拖动；修改端点时会尽量保持原轨迹形状。
- 多点点击：虚线只表示这个动作内部的点击顺序，不代表鼠标会沿线移动。圆点中的 `1 / 2 / 3…` 是内部点击顺序；旁边的胶囊数字才是宏时间线中的动作序号。
- 滚动：显示滚轮方向、幅度和执行锚点，不再伪装成点击十字，也不会把滚动采样位置画成鼠标移动轨迹。
- 鼠标移动：只强调最终目的位置，并使用光标样式；不会显示点击脉冲。
- 文字定位输入：文字框是录制时观察到的目标证据，不直接拖动；搜索范围才是 OCR 的可编辑空间。双击、长按、滚动等动作即使使用文字定位，也继续保留自己的动作语义。
- 目标文字标签：完整文字会在独立卡片中自动换行，不再被目标框或搜索区域的宽度截断。
- 搜索范围：显式搜索范围被选中后，拖顶部手柄可以整体移动，拖四角可以缩放；区域会被限制在对应窗口范围内。没有显式搜索范围时，虚线框表示“搜索整个目标窗口”，不会伪装成一个可拖的小区域。
- 坐标回退点：只有动作启用了“使用回退点”时才显示，但在编辑器中会一直可见，而不是等播放失败时才出现。选中该动作后可以直接拖动回退点；编辑结果会同时维护 Text Anchor 的绝对与内容区归一化备用坐标。
- 等待文本 / 验证文本：显示 OCR 搜索区域和完整目标文字，不显示点击脉冲。等待/验证条件本身没有“点击位置”。
- 键盘输入、纯等待、行为容器：没有屏幕空间目标，因此不会为了“有东西可画”而制造无意义的坐标标记。

同时开启`预览`和`轨迹`并单选一个动作时，当前动作保持完整强调，其他动作作为全局概览自动降噪。Fallback、目标文字卡片和搜索区域编辑手柄属于所选动作的详细预览，不会在纯`轨迹`模式里伪装成可编辑控件。

预览对 Playback Surface 的状态有明确区分：

- 当前目标窗口存在：直接按当前窗口和当前内容区几何显示，和真实播放使用同一套窗口内容区解析结果。
- 已绑定目标窗口，但窗口被隐藏、最小化或尚未打开：不继续把录制时的绝对坐标画在旧屏幕位置；编辑器会在当前编辑器所在屏幕中央模拟录制窗口边界，并把文字目标、搜索范围和回退点投影到这个模拟窗口中。
- 尚未绑定目标窗口，但动作仍有历史位置：优先保留上一次记录的位置，并用模拟窗口边界明确提示“尚未绑定目标窗口”。
- 尚未绑定且历史位置已经不在当前显示器上，或没有可用的历史几何：才退回当前屏幕中央的模拟窗口，避免把目标画到不可见区域。

模拟窗口只是编辑器的空间参照，不会把“未绑定窗口”伪装成可执行状态；真正播放前仍需完成目标窗口绑定。

## OCR 选择流程

把普通点击的定位方式切换为“文本 (OCR)”后，策略会立即保存，并显示目标文字、超时和缺失文字处理选项。切换策略本身不会开始截图识别。

点击文字拾取按钮后，系统会截图并识别目标窗口内容。

Picker 打开后会先倒计时 3 秒。倒计时结束前 OCR 框不会响应 hover 或点击，避免鼠标还停在 SparkleRecorder 自己按钮上时误触发。

倒计时结束后，把鼠标移动到目标文字上。橙色边框表示当前 hover 的文字框；淡橙色区域表示运行时优先搜索的区域。

点击文字后，动作会保存：

- 文字内容。
- 文字框位置。
- 搜索范围。
- 内容区归一化坐标。
- 坐标回退点。

## 找不到文字时

暂停：找不到目标文字时停止播放。这是默认策略，避免误点。

使用回退点：找不到文字时点击录入时保存的回退坐标。只建议在页面布局非常稳定时使用。

## 行为绑定

选中连续的一组动作后，可以使用“绑定为行为”把它们显示成一个行为块。

行为块适合表达一段完整意图，例如“打开菜单并选择导出”、“等待确认按钮并点击”、“拖动滑块后验证结果”。

绑定后排序会以整块为单位移动；“解除绑定”可以重新展开为独立动作。
